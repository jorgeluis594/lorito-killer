# Filter bar mobile stories

Keep `FilterBar` production code unchanged. Add three Storybook examples that
exercise quick filters, search with the filter trigger, and wrapping with many
filters at 390 px and 320 px viewports.

The stories reuse the existing `Input`, `ToggleGroup`, and `FilterTrigger`
components and Storybook's viewport globals. Validation is limited to lint,
Storybook build, and visual inspection of the mobile stories.
